01문제

피트스톱은 약 20초를 잃는 대신 신품 타이어를 얻습니다. 언제 들어가고 어떤 타이어를 끼울지가 레이스를 가릅니다.

타이어는 닳을수록 랩당 수십 밀리초씩 느려지다가 어느 지점(클리프)을 넘으면 급격히 떨어집니다. 먼저 들어가 신품으로 따라잡는 것이 언더컷, 상대가 들어간 사이 코스에 남아 앞서는 것이 오버컷입니다. 어느 쪽이 통하는지는 마모 속도, 피트 손실, 연료 무게, 트래픽에 달려 있습니다.

이 프로젝트는 그 판단을 공개 데이터로 재구성합니다. 팀 내부 센서 데이터 없이, 공개된 랩타임만으로 마모를 추정하고 전략을 비교합니다.

05방법

랩타임을 요인별로 분해하는 모델과, 그 계수를 데이터에서 뽑는 회귀.

시뮬레이션 모델

lapTime(n) = baseLap + 팀페이스 + 드라이버페이스 + 컴파운드델타 + 마모(선형 + 클리프) ← 클리프는 3.0초로 클램프 + 연료효과(n) ← 랩당 약 0.035초, 레이스 전체 1.9초 + 트랙진화(n) ← 지수 수렴 + 노면적합도 + 트래픽 + 노이즈 총시간 = Σ lapTime(n) + Σ 피트손실 ← 랩 단위 누적. 총합 근사 아님

매 랩을 계산해 누적합니다. 피트 랩을 1랩 옮기면 총시간이 0.75초 변합니다. 세이프티카는 서킷별 확률로 발생시키고, 몬테카를로에서는 모든 전략에 같은 세이프티카 타임라인을 줘서 공정하게 비교합니다.

마모 계수 추정 — 교락 분리

스틴트 안에서 타이어가 닳는 동안 연료도 같이 줄어듭니다. 단순회귀는 두 효과를 구분하지 못해 "타이어가 닳을수록 빨라진다"는 음수 기울기를 냅니다.

드라이버마다 피트 랩이 다르다는 점이 열쇠입니다. 절대 랩 번호와 타이어 나이가 완전히 공선적이지 않으므로 다중회귀로 분리할 수 있습니다.

랩타임 ~ a + b1·(절대 랩) + b2·(타이어 나이) b1 = 연료 + 트랙 진화 ← 음수여야 정상 b2 = 순수 마모 ← 양수여야 정상

세션마다 기준 랩타임이 크게 달라(스파 108초, 잔드보르트 73초) 전부 한 통에 넣지 않고 세션 × 컴파운드로 나눠 회귀한 뒤 중앙값으로 모았습니다.

09조사 문서 수식

자료 조사 문서의 수식 여섯 개로 타이어 항을 다시 계산하는 두 번째 모델. 시뮬레이터 1단계에서 기존 모델과 바꿔 가며 비교합니다.

F1 실제 스틴트 = min( √(2·T_pit/k₁), a_cliff, h₀/Δh_lap ) ← 타이어 수명. 넘는 스틴트는 후보에서 뺀다 F2 t_tire(a) = β₀ + β₁·a + β₂·(a − τ)₊ ← 클리프에서 꺾이는 열화 F3 T_track = (T_tire − q·T_air − b·v² − c) / p ← 타이어 온도에 대해 풀어서 쓴다 F4 Δt = a(T_min − T)² · 0 · b(T − T_max)² ← 적정 범위 밖 온도 보정 F5 k_c = t̄_c / t̄_M, 랩타임 = 미디엄 기준 × k_c ← 컴파운드 계수 F6 M = k·D_track·N, N_max = M_max / (k·D_track) ← 주행거리 마모 같은 양은 하나로 묶었다: k₁ = β₁, a_cliff = τ, h₀/Δh_lap = N_max

문서 모드에서 바뀌는 것은 타이어 항뿐입니다. 컴파운드 델타는 F5, 마모는 F2, 기존의 워밍업과 노면 온도에 따른 마모 증가는 F3·F4 로 바뀝니다. 문서의 "중복 금지"에 따라 기존 온도 항은 같이 쓰지 않습니다. 연료, 트랙 진화, 팀·드라이버 페이스, 비, 트래픽, 깃발은 두 모델이 같습니다. 서킷·팀·드라이버의 마모 배수는 문서 밖 요소라 기존 모델과 같은 값을 k₁ 에 곱합니다.

"직전 3랩 기울기 > 초반 기울기 × 2.5" 를 2랩 연속: 소프트 19개, 미디엄 55개, 하드 79개 스틴트에서 발동, 중앙값 9~10랩
원인
세 점으로 구한 기울기는 랩 사이의 작은 잡음에도 크게 흔들립니다
처리
클리프 판정에 쓰지 않음. 쓰려면 창을 늘리거나 잡음 수준 이상의 문턱이 필요

왜 다른가

소프트를 얼마나 타나

기존
소프트를 17~22랩까지 탑니다
문서
F1 수명이 소프트 14랩 · 미디엄 24랩 · 하드 30랩. 넘는 스틴트는 후보에서 뺍니다
결과
소프트 스틴트가 짧아지고, 그만큼 미디엄·하드를 더 쓰거나 한 번 더 섭니다

클리프를 넘기면

기존
클리프 이후 손실이 제곱으로 늘다가 3초에서 멈춥니다. 넘겨서 타도 손해가 작게 계산됩니다
문서
클리프 τ 가 F1 의 한 항이라, 클리프를 넘기는 스틴트 자체가 허용되지 않습니다
결과
두 모델의 차이는 대부분 τ 를 몇 랩으로 두느냐에서 나옵니다

온도

기존
노면이 최적 온도보다 뜨거우면 마모가 빨라집니다. 컴파운드마다 다르게 붙어 전략이 바뀔 수 있습니다
문서
F3 타이어 온도가 90~110°C 를 벗어날 때만 F4 보정이 붙고, 모든 컴파운드에 같습니다
결과
총시간만 바뀌고 전략 순위는 바뀌지 않습니다 (몬차 노면 55°C → 타이어 129°C → 랩당 +1.45초)

τ 는 경기 데이터에서 검출되지 않아 기존 모델의 클리프 랩을 그대로 씁니다 (위 "F2 — 클리프가 보이지 않는다"). 컴파운드별 클리프 랩을 조사 자료로 확인하면 두 모델의 결과 차이가 어디까지 줄어드는지 볼 수 있습니다. 시뮬레이터 1단계 계수 표에서 τ 를 바꾸면 바로 반영됩니다.

10한계

이 시뮬레이터가 다루지 않는 것.

단일 차량. 경쟁 차량이 없어 실제 추월이나 트래픽 영향을 시뮬레이션하지 않습니다. "언더컷"이라 부르지만 상대를 실제로 제치는 판정은 없습니다.

실버스톤만 실측 캘리브레이션. 나머지 23개 서킷의 baseLap·pitLoss·degMultiplier는 근사 초기값이라 3~5% 오차가 남아 있습니다. 시뮬레이터에서 "근사 초기값" 배지로 표시합니다.

선형 마모 모형. 클리프를 제곱항으로 근사하지만 실제 급락은 잡지 못합니다. 홀드아웃 오차의 주원인입니다.

상대 컴파운드. 몬차의 SOFT와 모나코의 SOFT는 실제로 다른 타이어(C1~C5)인데 같은 것으로 취급합니다. Pirelli 경기별 배정을 반영하는 것이 다음 과제입니다.

마모 계수 미반영. 6절에서 실측한 값을 아직 시뮬레이터 파라미터에 넣지 않았습니다. 컴파운드 간 차이를 얼마나 줄일지 판단이 먼저입니다.

회귀 결과는 물리적 마모가 아닙니다. 공개 랩타임에 나타난 "실전 페이스 저하"입니다. 드라이버가 타이어를 아껴 타면(리프트&코스트) 마모가 랩타임에 덜 드러납니다. 선행 논문도 같은 한계를 지적합니다.
