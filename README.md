# APEX Strategy v2

F1 타이어 전략 시뮬레이터. **F1 전략을 한국어로 이해하게 만드는 것**이 목표입니다.

정확도 경쟁에서는 이미 앞선 서비스들이 있습니다(PITWALL, f1strategysim, RaceMate — 전부 영어).
이 프로젝트가 비어 있는 자리를 채우는 방식은 두 가지입니다.

1. **한국어** — 조사(을/를) 처리까지 포함한 자연스러운 한국어. 용어 사전 내장.
2. **설명** — 모든 추천에 "왜 그 결론인지"가 문장으로 붙습니다. 숫자만 주지 않습니다.

---

## 실행

빌드 도구가 필요 없습니다. 정적 서버만 있으면 됩니다.

```bash
python -m http.server 8123
```

http://localhost:8123 접속. GitHub Pages에는 이 디렉터리를 그대로 push하면 됩니다.

> ES 모듈을 쓰기 때문에 `file://` 로 직접 열면 CORS 때문에 동작하지 않습니다. 반드시 서버로 여세요.

## 엔진 검증

브라우저 콘솔에서:

```js
APEX.runSelfTest()
```

10개 검증 항목이 실행됩니다 — 연료 효과, 클리프, 전략 격차, 피트 랩 민감도, 재현성,
랩타임 현실성, 추천 탐색, 24개 서킷 무결성 등.

```

src/

    simulate.js    랩 단위 메인 루프

    selftest.js    검증

  ui/            DOM 렌더링. engine/ 을 import 하지만 그 반대는 절대 없다
```

**`engine/` 이 `ui/` 를 import 하면 안 됩니다.** 이 경계 덕분에 엔진만 따로
테스트하고 캘리브레이션할 수 있습니다.

## 모델 요약

```
lapTime(n) = baseLap + 팀페이스 + 드라이버페이스 + 컴파운드델타
           + 마모(선형 + 클리프)      ← 클리프는 3.0초로 클램프
           + 연료효과                  ← 랩당 약 0.035초, 레이스 전체 약 1.9초
           + 트랙진화                  ← 지수 수렴
           + 노면적합도 + 트래픽 + 노이즈
```

- **랩 단위 누적.** 총합 근사가 아닙니다. 피트 랩을 1랩 옮기면 결과가 실제로 반응합니다.
- **재현 가능.** `mulberry32(seed)` — 같은 조건은 항상 같은 결과. URL로 공유됩니다.
- **몬테카를로 500회.** 매 회차 모든 전략에 **같은 SC 타임라인**을 줍니다.
  그래야 "이 SC 상황에서 어느 전략이 이겼나"를 공정하게 비교할 수 있습니다.
- **갭 분포.** 절대 완주 시간의 분산은 "SC가 났는가"가 지배해버려서 전략 비교에 못 씁니다.
  그래서 회차별 1위 대비 갭을 따로 집계합니다.

## 색 규칙

- **정체성 영역**(헤더, 버튼, 포커스, 차·헬멧 아트) → 팀 컬러. 원본 그대로, 절대 조정 안 함.
- **데이터 영역**(스틴트 바, 차트 선, 타이어 밴드) → 컴파운드 컬러 독점.
- 팀 컬러와 컴파운드의 ΔE(CIE76) < 25면 **데이터 영역에서만** 채도를 45% 낮춥니다.
  실측 결과 11개 팀 중 5개(레드불·페라리·하스·아우디·알핀)가 해당됩니다.
- 팀 컬러 위 텍스트 색은 상대 휘도로 자동 계산합니다. 임계값 0.179 는 WCAG 대비식의 교차점.
- 텍스트를 얹는 면에는 `--team-cta` 를 따로 계산해 4.5:1 을 보장합니다 — **11개 팀 전부 AA 통과, 최저 4.76:1**.

## 이미지

드라이버 사진 · 머신 렌더 · 팀 로고는 **F1 공식 미디어 CDN** 을 참조합니다.
URL 패턴은 v1 이 쓰던 것을 그대로 계승했고, `src/data/assets.js` 한 곳에 모여 있습니다.

```
차량    /common/f1/2026/{teamSlug}/2026{teamSlug}carright.webp
드라이버 /common/f1/2026/{teamSlug}/{driverSlug}/2026{teamSlug}{driverSlug}right.webp
로고    /common/f1/2026/{teamSlug}/2026{teamSlug}logowhite.webp
```

- 경로에 `d_(default)` 파라미터가 들어 있어, 해당 파일이 없으면 CDN 이 공식 실루엣을 줍니다.
- 그래도 네트워크 자체가 실패할 수 있으므로, **최종 폴백으로 인라인 SVG 아트**(`carArt.js`)로
  자동 교체됩니다. 이미지가 안 떠도 화면이 비지 않습니다.
- 그리드 슬롯은 Cloudinary 얼굴 인식(`c_thumb,g_face`)으로 정사각 크롭합니다.
- 검증 완료: **11개 팀 차량 · 로고, 22명 드라이버 사진 전부 로드**. 픽셀 해시로 확인한 결과
  22명 모두 고유 이미지이며 실루엣 폴백이 아닙니다.

**자체 호스팅으로 바꾸려면** `src/data/assets.js` 의 `LOCAL_ASSETS = true` 로 두고
`assets/cars/{teamId}.webp`, `assets/drivers/{driverId}.webp`,
`assets/faces/{driverId}.webp`, `assets/logos/{teamId}.webp` 를 넣으면 됩니다.

> 이 이미지들은 Formula One 의 자산입니다. 비영리 팬 프로젝트를 전제로 원본 CDN 을
> 그대로 참조하며 재배포하지 않습니다. 타이어 사이드월 색만은 SVG 폴백에서
> 현재 스타트 컴파운드를 따라갑니다.

## 데이터 주의사항

`src/data/circuits.js` 의 `baseLap` / `degMultiplier` / `scRate` 와
`src/data/teams.js` 의 `pace` / `degMultiplier` 는 **공개 정보 기반 근사 초기값**입니다.
실제 팀 데이터가 아닙니다.

현재 총 완주 시간은 실제 레이스보다 3~5% 낙관적입니다. 모델에 트래픽 추종,
리프트&코스트, 배틀 손실이 없기 때문입니다. **전략 간 상대 비교**는 유효하지만
절대 시간은 참고용으로만 보세요. 캘리브레이션은 `src/engine/params.js` 와
`src/data/circuits.js` 두 파일에서만 하면 됩니다.

2026 캘린더(24개 서킷)와 드라이버 라인업은 확인 후 수정하세요.
