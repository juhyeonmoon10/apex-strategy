# 런포런 3회차 활동 기록 — 선행연구 탐색·자료수집

- **활동일** 2026-08-28
- **모둠** 15팀 컴파운드 (박현중·이시형·주시우·문지상·문주현)
- **연구 주제** 데이터 분석을 통한 F1 타이어 전략 알고리즘 구현하기
- **이번 회차 목표** 타이어 전략 알고리즘의 근거가 될 선행연구를 조사하고, 실제 분석에 사용할 데이터 출처·변수·전처리 기준을 확정한다.

> 이 문서의 모든 수치는 실제로 실행한 결과다.
> 아직 구현하지 않은 것은 「계획」으로 따로 표시했다.

## 1. 오늘 활동 요약

F1 타이어 전략 선행연구 4편과 상용 서비스 4종을 조사하고, 데이터 출처를 OpenF1 API로 확정하였다. 2023–2025년 7개 서킷 21개 레이스에서 **23,048랩**을 수집해 **18,364랩**으로 정제하였다. 다중회귀로 연료 효과와 타이어 마모를 분리해 컴파운드별 마모 계수를 추정하였고, 스틴트 앞 75%로 학습해 뒤 25%를 예측하는 홀드아웃 검증에서 **MAE 0.717초**를 얻었다.

### 계획서 실천 계획 칸에 넣을 문장

> F1 타이어 전략 선행연구 4편과 상용 서비스를 조사하고 OpenF1 API를 데이터 출처로 확정하였다. 2023–2025년 7개 서킷 21개 레이스의 23,048랩을 수집하여 18,364랩으로 정제하고, 랩·스틴트·날씨 데이터를 랩 단위로 결합하였다. 다중회귀로 연료 효과와 타이어 마모의 교락을 분리하여 컴파운드별 마모 계수를 추정하였으며, 스틴트 시간순 홀드아웃 검증에서 MAE 0.717초를 확인하였다.

### 2-2. 추가 정독 — 연료·마모 분리 문제

**A State-Space Approach to Modeling Tire Degradation in Formula 1 Racing** (arXiv 2512.00640)

우리가 부딪힌 문제와 정확히 같은 문제를 다룬다. 랩타임이 느려지는 원인이 타이어인지 연료인지 관측만으로는 구분되지 않는다는 것.

```
관측식:  랩타임 = 잠재 타이어 페이스 + 연료 효과(γ) + 오차
상태식:  다음 페이스 = 이전 페이스 + 마모 증분(ν) + 과정 잡음
         피트스톱 = 상태를 초기화
```

- 데이터: FastF1, 2025 오스트리아 GP 해밀턴. 연료는 텔레메트리가 없어 110kg→0 선형 감소로 가정
- 평가: 스틴트별 rolling-origin 교차검증, **RMSPE 1.082초** (ARIMA 기준선 1.520초)
- 결과: HARD 0.054초/랩, MEDIUM 0.060초/랩
- **핵심 단서:** "신뢰구간이 크게 겹쳐 컴파운드 간 차이가 있다는 근거가 데이터에서 거의 나오지 않는다"

## 4. 데이터 출처 결정

| 순위 | 출처 | 사용 데이터 | 상태 |
|---|---|---|---|
| 1 | **OpenF1 API** | laps, stints, pit, weather, drivers | **채택 — 실제 사용 중** |
| 2 | FIA 공식 문서 | 경기 규정 | 조항 확인 예정 |
| 3 | Pirelli 보도자료 | 경기별 C1~C5 배정 | **[계획]** 4회차 |
| 4 | FastF1 | 2018년 이전 데이터 필요 시 | 미사용 |
| 5 | F1 TV Premium | SC·교통·팀 지시 정성 관찰 | **예산 검토 필요 (6절)** |

### OpenF1을 선택한 이유

- 인증 불필요, 2023년~ 전 세션 무료
- CORS 허용 → 웹사이트에서 서버 없이 직접 호출 가능
- `/stints`의 필드가 우리 데이터 모델과 1:1 대응
- 무료 제한 3req/s → 수집은 오프라인 스크립트로 수행

### 발견한 함정

`/pit`의 **`lane_duration`(28.75초)을 피트 손실로 쓰면 안 된다.** 이는 피트레인을 통과한 시간이지 코스에 남았을 때 대비 잃은 시간이 아니다.

```
실제 손실 = (인랩 + 아웃랩) − 2 × 정상 랩 = 19.9초   ← 실버스톤
```

약 9초 차이가 난다. 또한 `pit_duration`은 폐기 예정 필드이고, `stop_duration`(정지 시간)은 2024 미국 GP 이후에만 제공된다.

## 6. 예산 검토

계획서 예산에 두 가지 문제가 있다.

```
현재 계획서
  F1 TV PREMIUM    79,200원
  OpenAI 토큰     100,000원   ← 단가·금액 칸 비어 있음
  총액 표기        79,200원   ← 합산 오류. 실제 179,200원 → 10만원 초과
```

F1 TV는 **영상**이므로 수치 데이터를 자동 추출할 수 없다. 오늘 확인한 대로 필요한 데이터는 OpenF1에서 무료로 전부 얻었다.

| 안 | 내용 | 총액 |
|---|---|---|
| **A (권장)** | F1 TV 제외, OpenAI만 | **100,000원** ✅ |
| B | F1 TV 유지 (SC·교통 정성 관찰용), OpenAI 축소 | 79,200 + 20,800 = 100,000원 |

A안을 권장한다. SC·교통 사건은 OpenF1 `/race_control`에서 랩 단위로 확인 가능함을 오늘 검증하였다(2023 실버스톤: 33랩 VSC→SC, 38랩 해제).

## 7. 분석 결과

### 7-1. 왜 단순회귀는 실패하는가

스틴트 안에서 **타이어가 닳는 동안 연료도 같이 줄어든다.** 두 효과가 교락되어 단순회귀는 이런 결과를 낸다.

```
SOFT   −0.0305 초/랩
MEDIUM −0.0406 초/랩    ← 타이어가 닳을수록 빨라진다?
HARD   −0.0136 초/랩
```

부호가 명백히 틀렸다.

### 7-2. 다중회귀로 분리

**드라이버마다 피트 랩이 다르다**는 점이 열쇠다. 절대 랩과 타이어 나이가 완전히 공선적이지 않으므로 분리할 수 있다.

```
랩타임 ~ a + b1·(절대 랩) + b2·(타이어 나이)

b1 = 연료 + 트랙 진화   (음수여야 정상)
b2 = 순수 마모          (양수여야 정상)
```

세션마다 기준 랩타임이 크게 달라(스파 108초 vs 잔드보르트 73초) 세션 × 컴파운드로 나눠 회귀하고 중앙값으로 모았다.

### 7-3. 컴파운드별 마모

| 컴파운드 | b2 중앙값 | 사분위범위 | 세션 수 | 현재 모델 | 논문값 |
|---|---|---|---|---|---|
| SOFT | **+0.0597** | [+0.032, +0.079] | 13 | 0.055 | — |
| MEDIUM | **+0.0520** | [+0.027, +0.088] | 20 | 0.035 | 0.060 |
| HARD | **+0.0672** | [+0.054, +0.083] | 14 | 0.022 | 0.054 |

연료+트랙진화 `b1` 중앙값 **−0.0626초/랩**

**두 가지가 확인되었다.**

1. **논문값을 독립적으로 재현하였다.** 서킷·드라이버·방법이 모두 다른데 같은 범위가 나왔다.
2. **컴파운드 간 차이가 거의 없다.** 사분위범위가 서로 크게 겹친다. 논문의 지적과 일치한다. 현재 모델이 SOFT와 HARD를 2.5배로 벌려놓은 것은 데이터가 지지하지 않는다.

### 7-4. 서킷별 상대 마모

초/랩 절대값으로 비교하면 랩이 긴 서킷이 무조건 커진다. 랩타임 대비 백분율로 정규화하였다.

| 서킷 | 마모(%/랩) | 실측 비율 | 현재 모델 | 차이 |
|---|---|---|---|---|
| Spa-Francorchamps | 0.1071 | 1.30 | 1.15 | +0.15 |
| Suzuka | 0.0844 | 1.03 | 1.20 | −0.17 |
| Catalunya | 0.0837 | 1.02 | 1.20 | −0.18 |
| Hungaroring | 0.0823 | 1.00 | 1.05 | −0.05 |
| Zandvoort | 0.0488 | 0.59 | 1.10 | −0.51 |
| Monza | 0.0319 | 0.39 | 0.85 | −0.46 |
| Silverstone | 0.0289 | 0.35 | 1.25 | −0.90 |

정규화 전 스파는 1.78이었으나 정규화 후 1.30으로 내려갔다. **랩 길이 효과가 절반 이상이었다.**

### 7-5. 홀드아웃 검증

각 스틴트의 앞 75%로 학습하고 뒤 25%를 예측한다. 시간 순서를 지켜 미래 정보 누수를 막는다.

> 한 스틴트 안에서는 절대랩과 타이어나이가 완전히 공선적이므로(절대랩 = 시작랩 + 나이 − 1) 스틴트 하나로는 회귀가 불가능하다. **같은 세션·컴파운드의 여러 스틴트를 모아 학습**해야 공선성이 깨진다.

| 경기 | 예측 랩 | MAE(초) | RMSE(초) |
|---|---|---|---|
| 2025 Monza | 233 | **0.432** | 0.627 |
| 2023 Silverstone | 210 | 0.442 | 0.678 |
| 2025 Suzuka | 264 | 0.534 | 0.709 |
| 2023 Catalunya | 316 | 0.602 | 0.821 |
| 2023 Hungaroring | 299 | 0.613 | 0.860 |
| 2025 Zandvoort | 273 | 0.650 | 0.830 |
| 2025 Hungaroring | 331 | 0.659 | 0.856 |
| 2024 Spa-Francorchamps | 197 | 0.666 | 0.825 |
| 2024 Catalunya | 317 | 0.684 | 0.981 |
| 2023 Suzuka | 172 | 0.685 | 1.011 |
| 2023 Zandvoort | 173 | 0.703 | 0.990 |
| 2024 Monza | 249 | 0.707 | 0.890 |
| 2024 Suzuka | 207 | 0.820 | 1.042 |
| 2024 Hungaroring | 315 | 0.741 | 1.095 |
| 2025 Catalunya | 239 | 0.746 | 0.998 |
| 2024 Zandvoort | 353 | 0.655 | 0.851 |
| 2023 Spa-Francorchamps | 160 | 0.932 | 1.194 |
| 2025 Spa-Francorchamps | 159 | 0.975 | 1.145 |
| 2024 Silverstone | 123 | 1.261 | 1.711 |
| 2025 Silverstone | 105 | **2.170** | 3.007 |
| **전체** | **4,695** | **0.717** | **1.033** |

**해석**

- MAE 0.717초는 90초 랩 기준 약 **0.8%** 수준
- 논문의 RMSPE 1.082초와 비교해 우리 RMSE 1.033초는 유사한 범위
- **2025·2024 실버스톤이 최악**(2.170 / 1.261초)인데, 두 경기 모두 비가 왔다. `rainfall=0` 필터를 통과했더라도 노면이 마르는 중이면 랩타임이 급변해 선형 모형이 따라가지 못한다
- 선형 모형이라 **클리프**(급격한 성능 저하)를 잡지 못하는 것이 오차의 주원인

## 8. 시뮬레이터 캘리브레이션 (실버스톤)

수집한 데이터로 실버스톤 파라미터를 실측값으로 교체하였다.

| 항목 | 전 | 후 | 근거 |
|---|---|---|---|
| `baseLap` | 88.5 | **91.75** | 2023 건조 레이스 최속랩 90.275 + 모델 보정 |
| `pitLoss` | 23.5 | **19.9** | (인랩+아웃랩) − 2×정상랩 |
| 그린랩 평균 | 89.98 | **93.16** | 실측 93.115 → **오차 0.0%** |
| 완주 시간 | 4,676초 | **4,844초** | 목표 4,880초 → **오차 0.7%** |

캘리브레이션 전 3~5%였던 오차가 1% 이내로 들어왔다. 자체 검증 **12건 전부 통과**한다.

## 9. 오늘 배운 것 — 데이터 분석의 함정 3가지

| 함정 | 증상 | 해법 |
|---|---|---|
| **교락 (confounding)** | 마모 기울기가 전부 음수 | 다중회귀로 연료와 분리 |
| **필드 이름 오해** | `lane_duration` 28.75초를 피트 손실로 착각 | 정의를 따져 인랩+아웃랩 방식으로 재계산 → 19.9초 |
| **단위 미정규화** | 랩이 긴 서킷이 무조건 마모 커 보임 | %/랩으로 정규화 (스파 1.78 → 1.30) |

세 가지 모두 **숫자를 그대로 믿었으면 틀렸을** 경우다. 데이터가 있다는 것과 데이터를 옳게 읽는 것은 다른 문제라는 점을 확인하였다.

## 11. 4회차(9/4) 할 일

1. **FIA 규정 원문을 열어 조항 번호를 확인**하고 인용을 확정한다
2. 컴파운드별 마모 계수를 실측값으로 교체하고 정확도 변화를 측정한다
3. 컴파운드 간 차이를 줄일지 판단한다 — 논문·실측은 "차이 없음", 체감은 "차이 있음"
4. `degMultiplier` 실측값 반영 여부를 검토한다. 특히 실버스톤(1.25→0.35)은 건조 레이스가 3년 중 1회뿐이라 표본 보강이 먼저다
5. 바레인 GP를 표준 사례로 추가 수집하고 `TyreLife–랩타임` 산점도와 회귀선을 그린다
6. **[선택]** K-best 동적계획법 도입 검토 — 현재 전수 탐색보다 효율적이고 논문 근거가 있다
7. 예산안을 A안(F1 TV 제외, 10만원)으로 수정해 지도교사 확인을 받는다
