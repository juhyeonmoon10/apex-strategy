### 1-2. 1번 논문 정독 — 우리 방법과 가장 가까움

**문제의식이 우리와 같습니다.** 랩타임이 느려지는 원인은 두 가지인데(타이어 마모, 연료 감소) 관측된 랩타임에는 둘이 섞여 있습니다.

**모형**

```
관측식:  랩타임 = 잠재 타이어 페이스 + 연료 효과(γ) + 오차
상태식:  다음 페이스 = 이전 페이스 + 마모 증분(ν) + 과정 잡음
         피트스톱 = 상태를 α_reset 으로 초기화
```

**데이터·전처리**

- FastF1 API, 2025 오스트리아 GP 해밀턴
- 피트레인 랩 제거
- 연료는 텔레메트리로 못 받아서 **110kg에서 0으로 선형 감소**한다고 가정

**평가**

- 스틴트별 rolling-origin 교차검증
- RMSPE 1.082초 (ARIMA(2,1,2) 기준선 1.520초)
- CRPS 0.202 (기준선 0.324)
- 실행 시간 15~30초

**핵심 결과 — 우리에게 가장 중요한 부분**

> HARD 0.054초/랩, MEDIUM 0.060초/랩.
> 다만 **"신뢰구간이 크게 겹쳐 컴파운드 간 차이가 있다는 근거가 데이터에서 거의 나오지 않는다."**
> 저자들은 드라이버가 목표 랩타임을 맞추려고 타이어를 관리하기 때문이라고 본다.

## 3. 1차 분석 — 마모 계수 추정

### 3-1. 왜 단순회귀는 실패하는가

스틴트 안에서 **타이어가 닳는 동안 연료도 같이 줄어듭니다.** 두 효과가 교락(confounding)되어 단순회귀를 돌리면 이런 결과가 나옵니다:

```
SOFT   -0.0305 초/랩
MEDIUM -0.0406 초/랩     ← 타이어가 닳을수록 빨라진다?
HARD   -0.0136 초/랩
```

명백히 틀린 부호입니다. 연료 효과가 마모 효과보다 커서 그쪽이 이긴 것입니다.

### 3-2. 해법 — 다중회귀

**드라이버마다 피트 랩이 다르다**는 점이 열쇠입니다. 그래서 절대 랩 번호와 타이어 나이가 완전히 공선적이지 않고, 분리가 가능합니다.

```
랩타임 ~ a + b1·(절대 랩) + b2·(타이어 나이)

b1 = 연료 + 트랙 진화   (음수여야 정상)
b2 = 순수 마모          (양수여야 정상)
```

세션마다 기준 랩타임이 크게 달라서(스파 108초 vs 잔드보르트 73초) 전부 한 통에 넣으면 안 됩니다. **세션 × 컴파운드로 나눠 회귀하고 중앙값으로 모았습니다.**

### 3-3. 결과

```
컴파운드        b2 중앙값    사분위범위              세션수   현재 모델   논문값
SOFT           +0.0597    [+0.0323, +0.0787]     13      0.055      —
MEDIUM         +0.0520    [+0.0272, +0.0883]     20      0.035     0.060
HARD           +0.0672    [+0.0541, +0.0825]     14      0.022     0.054

연료+트랙진화 b1 중앙값   -0.0626 초/랩
```

**부호가 바로잡혔습니다.** 그리고 두 가지가 눈에 띕니다.

**① 논문값과 근접합니다.**
우리 MEDIUM 0.052 vs 논문 0.060, HARD 0.067 vs 논문 0.054.
서킷도 드라이버도 방법도 다른데 같은 범위가 나왔습니다. **독립적인 재현입니다.**

**② 컴파운드 간 차이가 거의 없습니다.**
SOFT 0.060 / MEDIUM 0.052 / HARD 0.067 — 사분위범위가 서로 크게 겹칩니다.
논문이 말한 **"컴파운드 간 차이의 근거가 약하다"** 와 일치합니다.

> **우리 모델은 SOFT(0.055)와 HARD(0.022)를 2.5배 차이로 벌려놨습니다.
> 실측 데이터는 이를 지지하지 않습니다.**

### 3-4. 서킷별 상대 마모

여기서 함정을 하나 발견했습니다. **초/랩 절대값으로 서킷을 비교하면 안 됩니다.**
스파(랩 108초)와 잔드보르트(73초)는 같은 비율로 닳아도 절대 손실이 다릅니다.

랩타임 대비 백분율로 정규화한 결과:

```
서킷                 마모(%/랩)   실측 비율   현재 모델   차이
Spa-Francorchamps     0.1071      1.30      1.15     +0.15
Suzuka                0.0844      1.03      1.20     −0.17
Catalunya             0.0837      1.02      1.20     −0.18
Hungaroring           0.0823      1.00      1.05     −0.05
Zandvoort             0.0488      0.59      1.10     −0.51
Monza                 0.0319      0.39      0.85     −0.46
Silverstone           0.0289      0.35      1.25     −0.90
```

정규화 전에는 스파가 1.78이었는데 정규화 후 1.30으로 내려갔습니다. **랩 길이 효과가 절반 이상이었습니다.**

## 4. 오늘의 결론

### 확인한 것

1. 한국어 F1 전략 시뮬레이터는 없다 → 주제의 차별점 확보
2. F1 TV PREMIUM 없이 무료 API로 필요한 데이터를 전부 얻을 수 있다
3. 23,048랩 데이터셋 확보, 전처리 후 18,364행 분석 가능
4. 마모 계수가 논문값과 같은 범위로 재현됨

### 배운 것 — 데이터 분석의 함정 3가지

| 함정 | 증상 | 해법 |
|---|---|---|
| **교락** | 마모 기울기가 전부 음수 | 다중회귀로 연료와 분리 |
| **필드 이름 오해** | `lane_duration` 28.75초를 피트 손실로 착각 | 인랩+아웃랩 − 2×정상랩 = 19.9초 |
| **단위 미정규화** | 랩이 긴 서킷이 무조건 마모 커 보임 | %/랩으로 정규화 |

세 가지 모두 **숫자를 그대로 믿었으면 틀렸을** 경우입니다.
