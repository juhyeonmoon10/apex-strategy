# 레이스 시뮬레이션 화면 조사 — 다른 서비스는 레이스를 어떻게 보여주나

2026-09-05. 스텝 3(레이스 재생)가 마음에 들지 않는다는 문제에서 출발해, 실제로 돌려 보고 화면을 확인한 것만 적는다.

## 0. 우리 화면(스텝 3)이 지금 하는 것

- 그래프 하나: 평균 페이스 대비 누적 시간차("레이스 트레이스")를 세 전략(예상 최속·안정 우선·공격적 대안)에 대해 그린다.
- 재생 버튼, 배속 1×/2×/5×, 슬라이더, "이 랩에서" 한 줄 문장, 접힌 몬테카를로.
- **경쟁 차량이 없다.** 같은 차의 전략 세 가지를 겹쳐 놓았을 뿐이라 추월도, 순위도, 상대와의 간격도 없다. 선은 타이어 마모로 서서히 내려가다 피트에서 툭 떨어지는 톱니 모양이 전부다.

레이스 트레이스는 팀과 전문 팬이 쓰는 도구다(MultiViewer, TracingInsights 의 Race Trace 가 같은 그래프). 정확하지만 읽는 법을 알아야 하고, "레이스가 벌어지는" 느낌은 없다.

## 1. 확인한 서비스와 보여주는 방식

## 2. 공통점 — 무엇이 "레이스"처럼 보이게 하나

1. **상대가 있다.** PITWALL 은 AI 라이벌, f1grid 는 실제 라이벌, 방송은 진짜 경쟁. 순위·갭·추월이 생겨야 화면에 사건이 생긴다.
2. **트랙 위를 움직이는 차.** PITWALL·f1grid·AWS 모두 트랙 윤곽(또는 원)에 점을 놓고 돌린다. 랩 카운터와 배속은 기본.
3. **타이밍 타워.** 순위·갭·인터벌·타이어 칩·순위 변화 화살표. 모든 리플레이가 갖고 있다.
4. **타이어 전략 간트.** 드라이버별 스틴트 막대에 현재 랩 커서. 레이스 전체가 한눈에 보인다.
5. **사건 로그.** "LAP 12 Rival-Beta overtakes Player" 같은 한 줄 목록. 만들기 쉽고 이야기가 된다.
6. **그래프는 뒤로.** 랩타임·갭·마모 그래프는 리플레이 아래에 두거나 탭에 넣는다. 첫 화면에 그래프만 두는 곳은 없었다.
7. **요약 카드가 먼저.** 우승자·완주 시간·추월 수·승률을 위에 크게.

## 3. 우리와의 차이

| | 다른 서비스 | 우리 스텝 3 |
|---|---|---|
| 경쟁 차량 | 있음 (3~22대) | 없음 — 같은 차의 전략 3개 |
| 첫 화면 | 요약 카드 + 트랙 리플레이 + 타이밍 타워 | 레이스 트레이스 그래프 |
| 사건 | 추월·피트·SC 가 순위에 나타남 | "이 랩에서" 문장 한 줄 |
| 그래프 | 아래쪽 보조 | 주인공 |

엔진은 이미 22명 드라이버의 페이스(EA 능력치)와 그리드 순서를 갖고 있고, 트래픽 항도 있다. 없는 것은 **여러 대를 같은 레이스에서 함께 돌리고 추월을 판정하는 부분**뿐이다(README 남은 작업 "경쟁 차량 → 진짜 언더컷 판정").

## 4. 제안 — 스텝 3 을 이렇게 바꾼다

1. **엔진: 다중 차량 레이스.** 내 차 + 그리드 앞뒤 4~6대(가라지 화면의 그리드 창과 같은 드라이버)를 같은 SC 타임라인에서 랩 단위로 함께 돌린다. 추월 판정은 단순 규칙으로 시작한다: 페이스 차 0.4초/랩 이상이고 갭 1.0초 이내면 다음 랩에 추월, 아니면 뒤차가 앞차 페이스에 묶임(트래픽 손실). 라이벌 전략은 각 차의 추천 1순위.
2. **트랙 리플레이.** F1 CDN 서킷 지도 위에 차 점을 놓고 랩 진행률로 움직인다. 랩 카운터, 재생·배속, 슬라이더는 지금 것을 그대로 쓴다. 지도가 없는 서킷(마드리드·바쿠)은 원형 트랙으로 대체.
3. **타이밍 타워.** 순위·이름·타이어 칩·리더 대비 갭·인터벌·▲▼. 내 차 행은 팀 컬러.
4. **타이어 전략 간트 + 랩 커서.** 드라이버별 스틴트 막대. 피트 지점에 마커.
5. **사건 로그.** 기존 narrate.js 를 확장해 추월·피트·언더컷 성패·SC 를 한 줄씩 쌓는다. "L19 러셀 피트 → L21 언더컷 성공, 노리스 앞으로".
6. **요약 카드**를 맨 위에: 최종 순위, 완주 시간, 추월 수, 승률(몬테카를로).
7. 레이스 트레이스는 접힌 "자세히 보기"로 내린다. 언더컷 설명이 나올 때는 AWS 식 원형 트랙 미니 애니메이션을 근거 문장 옆에 붙인다.

작업량은 엔진(다중 차량·추월)이 한 회차, 화면(리플레이·타워·간트·로그)이 한 회차 정도다.
