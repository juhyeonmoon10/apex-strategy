## 2. 코덱스판이 앞서는 것

1. **검증 서사가 완성돼 있다.** 완전탐색 대조 PASS, 실제 전략 백테스트, 민감도, 정제 단계별 랩 수 깔때기(1,126 → 974), 컴파운드별 95% 구간 표. 발표·보고서용 근거가 화면에 그대로 있다.
2. **실데이터를 실제로 모델에 넣었다.** 신뢰 기준 통과 계수만 서킷별로 적용하는 규칙(11/15)이 명확하다. 우리는 계수를 재고도 아직 params 에 안 넣었다.
3. **3D 리플레이**는 시각적 임팩트가 크다. 20대가 실제 서킷 윤곽 위를 달리고 타이어 상태 수치가 랩마다 바뀐다.
4. **실험 노트·CSV**는 탐구 보고서 흐름과 바로 이어진다.
5. 자산 출처·라이선스를 하나하나 밝혔다.

## 3. 이 저장소가 앞서는 것

1. **레이스가 벌어진다.** SC/VSC 타임라인을 모든 전략에 똑같이 주고 500회 돌린 승률, 언더컷·오버컷 교차 지점 탐지, 트래픽. 코덱스판은 "SC/VSC·추월·상대 대응 제외"를 명시한 결정론 모델이라 Top 3가 셋 다 **1:19:52.311 동률**로 나온다(스틴트 순서만 바뀐 같은 답).
2. **한국어 설명.** 모든 추천에 조사까지 맞춘 근거 문장이 붙는다. 코덱스판은 숫자와 라벨 위주고 영어 장식 문구가 남아 있다.
3. **데이터 양**: 23,048랩(7서킷·3시즌) vs 5,799랩(5경기·1시즌).
4. **팀·드라이버가 결과에 들어간다.** 코덱스판은 "팀·선수 선택은 Top 3 계산에 영향 없음".
5. **가벼움**: 빌드 도구 없이 바로 열리고, 번들 561KB 대신 필요한 모듈만 받는다.
6. 보드가 피렐리 원본과 픽셀 단위로 맞고 전부 한국어다. 드래그 편집이 화면 깜빡임 없이 된다.

## 4. 코덱스판에서 가져올 만한 것 (우선순위)

1. 측정한 마모 계수를 서킷별로 params 에 반영하고, 신뢰구간 기준을 두어 통과한 것만 쓰기 — 우리 데이터가 더 많으니 더 잘 될 일.
2. 실제 전략 백테스트 페이지: 2025 실버스톤 상위 3명의 실제 전략을 우리 모델에 넣어 "모델 최적 대비 +x초"를 보여준다.
3. 브라우저 자체 검사 12항목을 콘솔이 아니라 연구 페이지에 PASS/FAIL 로 표시.
4. 실험 노트(조건+결과 저장, CSV).
5. 열화 ±10% 민감도 한 줄.

3D 는 임팩트는 크지만 모델과 분리된 연출이라(본인들도 "전략 계산과 분리된 시각화"라고 씀) 우선순위는 뒤.

## 5. 코덱스판에서 피할 것

- 영어 장식 문구(YOUR ENTRY, EQUAL FASTEST, STRATEGY LAB) — 이미 우리 기준에서 뺀 것.
- 동률 Top 3 — 순서만 바꾼 같은 전략을 세 개로 보여주면 추천의 의미가 없다. 우리는 스톱 수·성격이 다른 세 개를 낸다.
- 푸터의 "학교 프로젝트" 표기.
