# 전략 보드 픽셀 검수 — 실제 F1·피렐리 타이어 전략 UI 조사

2026-09-04. 검수 도구: `docs/ui-audit.html` (dev 서버에서 `/docs/ui-audit.html`). 원본 이미지는 `docs/reference/`.

## 1. 실제로 쓰이는 공식 그래픽은 두 계열이다

| 계열 | 어디에 | 파일 | 특징 |
|---|---|---|---|
| **피렐리 "Possible Race Strategies" (2026)** | 피렐리 프레스·SNS, 매 경기 토요일 배포. "Rights free for media use" | `pirelli_gb26_strategies.png` (영국, 1500×844) · `pirelli_ca26_strategies.png` (캐나다, 1980×1114) | 검정 배경, **3px 선** 위에 실사 타이어, `LAP 24 TO 30` 텍스트, 오른쪽 `ONE-STOPPER` 라벨 |
| **F1.com "Expected Pit Stop Strategies & Windows" (2025)** | formula1.com 「PIRELLI STRATEGY GUIDE」 기사 | `be25_expected_strategies.png` (벨기에, 1920×1080) + 타이어 보유·페이스·피트 손실 차트 3장 | 흰 배경 간트 막대, 초록 피트 윈도우 블록, 랩 눈금 |

우리가 지금까지 따라 한 것은 2024~2025년 피렐리 그래픽(굵은 막대 + "THE QUICKEST TWO-STOPPER")이다. 2026년 그래픽은 그 형식을 버리고 **얇은 선 + 타이어 + 짧은 텍스트**로 바뀌었다. 두 경기(영국·캐나다)를 비교했을 때 비율이 같으므로 템플릿이 고정돼 있다고 봐도 된다.

## 4. 우리 보드와의 차이 (폭 1500 으로 맞춰 실측)

| 항목 | 피렐리 2026 | 우리 | 판정 |
|---|---|---|---|
| 형태 | 3px 선 | 40px 둥근 막대 + 그림자 | ✗ 계열 자체가 다름 |
| 행 간격 | 128px | 102px | ✗ |
| 선 시작 / 끝 x | 31 / 1410 | 56 / 1152 | ✗ 오른쪽에 라벨 열(190px)이 있어 선이 짧음 |
| 끝 타이어 중심 x | 1441 | 1428 | △ |
| 피트 타이어 지름 | 66 | 50 | ✗ (평면 SVG vs 실사 3D) |
| 범례 타이어 지름 | 72 | 96 | ✗ 우리가 더 큼 |
| 윈도우 글자 | 24px, `LAP` 일반 + 숫자 볼드, 선 위 | 14px 볼드, 막대 안 | ✗ |
| 오른쪽 라벨 | 24px `ONE-STOPPER` 만 | 21px 등급 + 스톱 수 + 시간 3줄 | △ 정보량은 우리가 많음 |
| 제목 | 48px 대문자 왼쪽 정렬 | 32px 가운데 정렬 | ✗ |
| 소제목 | 23px | 14px | ✗ |
| 배경 | 순검정, 테두리 없음 | 카드(그라데이션 #1c1f24→#121417, 테두리, 6px 모서리) | ✗ |
| 색 | #d81d21 / #f6c847 / #ebebeb | #da291c / #ffd12e / #f0f0ec | ○ 거의 같음 |
| 글꼴 | Titillium Web | Pretendard | △ 한국어라 대체 필요 |

정리하면 색만 맞고 나머지는 전부 다르다. 2026 원본을 따르려면 막대를 선으로 바꾸고, 윈도우 텍스트를 타이어 왼쪽 위로 올리고, 오른쪽 라벨 열을 없애 선을 끝까지 늘리고, 카드 테두리를 없애는 것이 핵심이다.
